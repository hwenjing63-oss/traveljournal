连接你的 OpenAI

  1. 在 OpenAI 平台创建 API 密钥。
  2. 在项目根目录把 .env.example 复制为 .env，并在本地填入密钥。
  3. 双击「启动拾途.cmd」，在本地服务页面使用 AI。

不要把密钥放进网页或发到聊天中。API 使用需要账户具有可用额度。
